# 🌳 Деревья решений и ансамблевые методы: классификация рисков на аукционах

**Decision Trees | Random Forest | GBDT | XGBoost | LightGBM | CatBoost | Реализация с нуля**

---

## 📌 Описание проекта

Этот проект посвящен глубокому изучению деревьев решений и ансамблевых методов машинного обучения на примере задачи бинарной классификации — выявления дефектных автомобилей ("лимонов") по данным аукционных продаж.

**Ключевая особенность:** Все основные алгоритмы (Decision Tree, Random Forest, GBDT) реализованы **с нуля** с использованием только NumPy, что демонстрирует глубокое понимание их математических основ. Дополнительно проведено сравнение с библиотечными реализациями (sklearn, XGBoost, LightGBM, CatBoost).

**Бизнес-ценность:** Модель может быть использована для создания скоринговой системы оценки качества автомобилей на аукционах, позволяя минимизировать финансовые потери от покупки проблемных автомобилей.

---

## 🎯 Задачи проекта

1. Реализовать **Decision Tree Classifier** с нуля (Gini impurity, рекурсивное разбиение).
2. Реализовать **Random Forest Classifier** с нуля (бэггинг, случайные подпространства).
3. Реализовать **GBDT Classifier** с нуля (градиентный бустинг на деревьях с MSE-критерием).
4. Реализовать **ExtraTrees Classifier** с нуля (случайные пороги разбиения).
5. Сравнить кастомные реализации с библиотечными аналогами (`sklearn`, `XGBoost`, `LightGBM`, `CatBoost`).
6. Проанализировать проблему переобучения и выбрать оптимальную модель.
