# Прогнозирование стоимости аренды жилья с линейными моделями

**Задача:** Разработка моделей регрессии для предсказания цены аренды квартиры с использованием линейных моделей, регуляризации и ансамблевых методов.

**Статус:** ✅ Завершен. Реализован полный ML-пайплайн от EDA до production-готовой модели.

---

## 📌 Описание проекта

В этом проекте реализован полный цикл машинного обучения для задачи регрессии. Основной фокус — на линейных моделях: от реализации градиентного спуска "с нуля" до использования регуляризации (Ridge, Lasso, ElasticNet). Дополнительно обучены ансамблевые модели (RandomForest, GradientBoosting) для сравнения.

Ключевая особенность — **собственная реализация линейной регрессии** с использованием стохастического градиентного спуска, что демонстрирует глубокое понимание математических основ ML.

## 🎯 Выполненные задачи

- **EDA:** анализ распределений, выбросов, корреляций
- **Feature Engineering:** создание 20 бинарных признаков из текстового поля `features`
- **Реализация "с нуля":** линейная регрессия с SGD (batch_size, learning rate, epochs)
- **Регуляризация:** Ridge (L2), Lasso (L1), ElasticNet (L1+L2)
- **Нормализация:** StandardScaler для признаков и целевой переменной
- **Обучение моделей:** 9 моделей (линейные, регуляризованные, деревья, ансамбли)
- **Наивные модели:** сравнение с предсказанием средним и медианой
- **Оценка качества:** MAE, RMSE, R² на валидационной выборке

🔍 Особенности реализации
1. Линейная регрессия "с нуля"
Реализован класс LinearRegressionSGD с:

Стохастический градиентный спуск (batch_size=256)

Настраиваемые гиперпараметры: learning rate, epochs, seed

Отслеживание сходимости (loss history)

Сравнение с sklearn.LinearRegression (разница R² < 0.001)

2. Инженерия признаков
22 признака: bathrooms, bedrooms + 20 бинарных признаков из features

Топ-20 удобств отобраны через Counter (Elevator, HardwoodFloors, CatsAllowed, etc.)

Нормализация названий признаков для устранения дубликатов

3. Обработка данных
Удаление выбросов по 1-му и 99-му процентилям price

StandardScaler для признаков и целевой переменной

Разделение на train/validation (80/20, random_state=42)

4. Гиперпараметры
GridSearchCV для Ridge, Lasso, ElasticNet, DecisionTree

Подбор alpha и l1_ratio для регуляризованных моделей
