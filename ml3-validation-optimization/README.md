# Методы валидации и оптимизации моделей

**Задача:** Реализация и сравнение методов кросс-валидации, отбора признаков и оптимизации гиперпараметров для задачи прогнозирования стоимости аренды жилья.

**Статус:** ✅ Завершен. Реализованы 4 схемы валидации, 4 метода отбора признаков и 3 подхода к оптимизации гиперпараметров.

---

## 📌 Описание проекта

В этом проекте реализован глубокий анализ методов оценки качества моделей машинного обучения. Основные направления:

1. **Схемы валидации** — реализация "с нуля" K‑Fold, Group K‑Fold, Stratified K‑Fold и Time Series Split с последующим сравнением с sklearn.
2. **Отбор признаков** — применение 4 методов: веса Lasso, корреляционный фильтр, Permutation Importance и SHAP.
3. **Оптимизация гиперпараметров** — сравнение Grid Search, Random Search и Optuna (включая Optuna с кросс-валидацией).

Проект демонстрирует навыки реализации алгоритмов "с нуля" и профессионального использования библиотек.

## 🎯 Выполненные задачи

### 1. Теория
- Leave-One-Out: сильные и слабые стороны
- Grid Search, Randomized Search, Bayesian Optimization
- Классификация методов отбора признаков (Filter, Wrapper, Embedded)
- Pearson, Chi², Lasso, Permutation Importance, SHAP

### 2. Разделение данных
- Случайное разделение на 2 и 3 части (train/val/test)
- Разделение по дате на 2 и 3 части
- Детерминированность разбиений (random_state)

### 3. Кросс-валидация (реализация "с нуля")
- K‑Fold
- Group K‑Fold (группировка по manager_id)
- Stratified K‑Fold (стратификация по interest_level)
- Time Series Split (по дате создания)

### 4. Сравнение схем валидации
- Оценка модели Ridge(alpha=1.0) на 5 фолдах
- Сравнение с реализациями sklearn
- Выбор лучшей схемы для данных

### 5. Отбор признаков
- **Lasso weights** — сортировка по модулю коэффициентов
- **Correlation filter** — отбор по корреляции с target
- **Permutation Importance** — модельно-независимый метод
- **SHAP** — интерпретация с помощью Shapley values

### 6. Оптимизация гиперпараметров
- **Grid Search** — полный перебор
- **Random Search** — случайный поиск
- **Optuna** — байесовская оптимизация
- **Optuna + CV** — с внутренней кросс-валидацией

## 📊 Результаты

### 1. Сравнение схем кросс-валидации
Оценка на модели Ridge(alpha=1.0), 5 фолдов.

| Метод | MAE (среднее) | MAE (std) | R² (среднее) |
| :--- | :---: | :---: | :---: |
| **K‑Fold** | **710.73** | **6.32** | **0.5806** |
| Stratified K‑Fold | 710.80 | 9.02 | 0.5807 |
| Group K‑Fold | 714.51 | 37.68 | 0.5723 |
| Time Series | 709.92 | 10.53 | 0.5848 |

**Вывод:** K‑Fold показывает лучшую стабильность. Time Series даёт нестабильные результаты — данные не имеют сильной временной зависимости.

### 2. Отбор признаков
Базовая модель: Lasso(alpha=1.0) на всех 23 признаках.

| Метод | Кол-во признаков | MAE (val) | R² (val) | Δ MAE |
| :--- | :---: | :---: | :---: | :---: |
| **Все признаки (база)** | 23 | **711.05** | **0.577** | — |
| Lasso weights (top-10) | 10 | 714.26 | 0.573 | +3.21 |
| Permutation (top-10) | 10 | 715.18 | 0.572 | +4.13 |
| SHAP (top-10) | 10 | 717.10 | 0.571 | +6.05 |
| Correlation (top-10) | 10 | 722.45 | 0.566 | +11.40 |

**Топ-5 признаков по весам Lasso:**
1. `bathrooms` — количество ванных
2. `bedrooms` — количество спален
3. `Doorman` — наличие консьержа
4. `LaundryinUnit` — стиральная машина
5. `LaundryInBuilding` — прачечная

### 3. Оптимизация гиперпараметров (ElasticNet)

| Метод | Итераций | Время (с) | Лучшая MAE | Параметры (α, l1_ratio) |
| :--- | :---: | :---: | :---: | :--- |
| Grid Search | 48 | 19.74 | **711.09** | (1.93, 1.0) |
| Random Search | 48 | 12.83 | **711.09** | (1.93, 1.0) |
| Optuna (base) | 50 | **1.96** | 711.49 | (0.00013, 0.97) |
| **Optuna + CV (5)** | 50 | 7.56 | **709.38** | (0.00013, 0.97) |

**Вывод:** Optuna с кросс-валидацией дал лучшее качество (MAE = 709.38) за 7.56 секунд. Grid Search и Random Search показали одинаковый результат (711.09), но затратили больше времени.

### 4. Финальная модель
- **Алгоритм:** ElasticNet
- **Alpha:** 0.000133
- **L1_ratio:** 0.970
- **Test MAE:** 711.89
- **Test R²:** 0.572

## 🔍 Особенности реализации

### 1. Кросс-валидация "с нуля"
Реализованы 4 схемы без использования sklearn:
- `k_fold_split()` — равномерное разбиение
- `group_k_fold_split()` — группировка по полю
- `stratified_k_fold_split()` — стратификация классов
- `time_series_split()` — расширяющееся окно

### 2. Feature Selection
- **Lasso:** L1-регуляризация обнуляет веса слабых признаков
- **Correlation filter:** удаление высококоррелированных признаков
- **Permutation Importance:** оценка важности через перемешивание
- **SHAP:** Shapley values для интерпретации

### 3. Hyperparameter Optimization
- **Grid Search:** полный перебор 48 комбинаций
- **Random Search:** случайный выбор 48 комбинаций
- **Optuna:** байесовская оптимизация с TPE sampler
