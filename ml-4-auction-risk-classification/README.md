# Прогнозирование дефектных автомобилей ("Lemon Cars") на аукционах

**Цель проекта** — разработка и сравнение моделей машинного обучения для выявления автомобилей с высоким риском дефектов ("лимонов") на основе данных об аукционных продажах. Основной фокус сделан на детальный анализ данных, построение и сравнение нескольких классификаторов, а также на глубокое понимание математических основ алгоритмов.

## 📌 Описание проекта

Этот проект посвящен бинарной классификации для задачи обнаружения автомобилей, покупка которых оказалась неудачной (IsBadBuy = 1). Задача является классической для области управления рисками и может быть использована для построения скоринговых систем на аукционах.

Проект включает полный цикл работы: от первичного анализа и очистки данных до построения и сравнения нескольких моделей, включая кастомные реализации, написанные "с нуля", что демонстрирует глубокое понимание математических основ.

## 🎯 Задачи проекта

*   Спрогнозировать метку `IsBadBuy` для автомобилей на основе их характеристик (пробег, возраст, цена, марка, модель и др.).
*   Сравнить эффективность стандартных алгоритмов: **Logistic Regression**, **Naive Bayes**, **K-Nearest Neighbors**.
*   Реализовать эти алгоритмы **самостоятельно**, используя только базовые библиотеки (NumPy), для подтверждения понимания их внутреннего устройства.
*   Исследовать методы повышения качества предсказаний: создание новых признаков, отбор признаков и настройка гиперпараметров.
*   Провести анализ метрик, критичных для бизнеса, и обосновать выбор оптимальной модели и порога классификации.

## 📁 Структура проекта

Основная работа выполнена в Jupyter Notebook.

*   **EDA и Предобработка данных:**
    *   Временное разбиение выборки (Train/Valid/Test по дате покупки `PurchDate`).
    *   Обработка пропусков (заполнение медианой и модой).
    *   Кодирование категориальных признаков (One-Hot для низкокардинальных, Count Encoder для высококардинальных).
    *   Нормализация числовых признаков.
*   **Моделирование:**
    *   Построение базовых моделей (`sklearn`).
    *   Реализация моделей "с нуля" (`MyLogisticRegression`, `MyKNN`, `MyGaussianNB`).
    *   Оценка качества (Gini Score, ROC-AUC, Precision, Recall, F1).
*   **Улучшение качества:**
    *   Создание нелинейных признаков (взаимодействия, отношения).
    *   Отбор признаков на основе важности.
    *   Настройка гиперпараметров (GridSearchCV) и выбор оптимального порога классификации.

## 📊 Основные Результаты

### Сравнение моделей на тестовой выборке

| Модель | Gini Score (Test) | ROC-AUC | Recall (Порог 0.16) | Precision |
| :--- | :---: | :---: | :---: | :---: |
| **LogisticRegression (sklearn)** | **0.3593** | 0.6797 | 0.1030 | 0.3406 |
| **MyLogisticRegression** | **0.3568** | 0.6784 | 0.2465 (Порог 0.16) | 0.2606 |
| **GaussianNB** | 0.3535 | 0.6767 | 0.2611 | 0.2505 |
| **KNN** | 0.1633 | 0.5817 | - | - |

### Ключевые выводы

1.  **Лучшая модель:** `LogisticRegression` из библиотеки `sklearn` показала наилучший результат по метрике Gini (0.3593), что значительно превышает базовое требование (0.15).
2.  **Кастомные реализации:** Модели, написанные вручную (`MyLogisticRegression`, `MyGaussianNB`), показали результаты, близкие к библиотечным, что подтверждает их математическую корректность.
3.  **Бизнес-ценность:** Оптимизация порога принятия решения (0.16 вместо стандартного 0.5) позволила значительно увеличить полноту (Recall) обнаружения проблемных автомобилей (с 0.3% до 24.6%), что критично для данной бизнес-задачи, где цена пропуска дефектного автомобиля очень высока.
4.  **Стабильность:** Модель `MyLogisticRegression` показала минимальный разброс метрик между обучающей, валидационной и тестовой выборками, что свидетельствует о её устойчивости к переобучению.

## 🔍 Особенности реализации

*   **Реализация логистической регрессии с нуля:** Класс `MyLogisticRegression` реализует градиентный спуск для минимизации логистической функции потерь. Продемонстрировано понимание процесса обучения и работы с градиентами.
*   **Реализация Naive Bayes с нуля:** Класс `MyGaussianNB` воспроизводит вычисления апостериорных вероятностей, используя предположение о нормальном распределении признаков, что позволяет лучше понять внутреннее устройство алгоритма.
*   **Реализация KNN с нуля:** Класс `MyKNN` использует евклидово расстояние для поиска ближайших соседей и показывает, как работает "ленивое" обучение.
