# 🏠 Прогнозирование стоимости аренды жилья

**Задача:** Разработка модели машинного обучения для предсказания цены аренды квартиры на основе характеристик объявления.

**Статус:** ✅ Завершен

---

## 📌 Описание проекта

Модель регрессии для прогнозирования цены аренды на основе:
- Количество ванных комнат (`bathrooms`)
- Количество спален (`bedrooms`)
- Уровень интереса пользователей (`interest_level`)

Проведён полный цикл: анализ данных → создание признаков → обучение моделей → сравнение результатов.

## 🎯 Выполненные задачи

- **EDA:** анализ распределений, выбросов, корреляций
- **Feature Engineering:** создание полиномиальных признаков (квадраты)
- **Обучение моделей:** Linear Regression, Decision Tree
- **Naive модели:** сравнение со средним и медианой
- **Оценка качества:** MAE и RMSE на train/test

## 📊 Результаты

### Сравнение моделей

| Модель | MAE (test) | RMSE (test) |
| :--- | :---: | :---: |
| **Decision Tree** ✅ | **759.53** | **1089.23** |
| Linear Regression | 786.23 | 1130.13 |
| Naive Mean | 1143.08 | 1591.30 |
| Naive Median | 1092.70 | 1639.38 |

### Ключевые выводы

- **Decision Tree** показал лучший результат по обеим метрикам
- Модель устойчива к переобучению (близкие значения на train/test)
- Самый значимый признак — количество ванных комнат (корреляция 0.67)

## 🔍 Особенности реализации

- **Обработка выбросов:** удаление записей за пределами 1-го и 99-го процентилей
- **Кодирование категорий:** `interest_level` (low→0, medium→1, high→2)
- **Полиномиальные признаки:** созданы квадраты признаков для проверки нелинейных связей
- **Сравнение подходов:** 4 модели для выбора лучшей
